# WYS feedback

Report bugs and suggest improvements for **WYS: What You Said**, published by **Otter Appworks**. WYS transcribes audio and video on your device. The Mac edition supports Apple Silicon and macOS 14 or later, with additional speaker and review features. The iPhone/iPad edition targets iOS/iPadOS 26 or later and focuses on file transcription, playback, search and export. Features differ by platform.

This public repository contains user feedback and support documentation only. Application source code and app downloads are not hosted here. The Mac and iPhone/iPad editions are being prepared for App Store review and are not yet on sale.

- [Suggest an improvement](https://github.com/elzuzu/wys-feedback/issues/new?template=feature-request.yml)

- Other questions: **wys@elzuzu.ch.eu.org**

Please write reports **in English or French**. Include the WYS version (**WYS → About WYS** on Mac, **Settings → Version** on iPhone/iPad), the OS version, device model and steps that lead to the problem.

**Issues and attachments are public.** Never attach a recording, a transcript or anything that contains other people's voices or private information: describe the problem instead, or reproduce it with a synthetic sample. Remove personal paths, names, documents, credentials and account information. The app never submits reports or logs by itself.

WYS is independent and is not affiliated with Apple. A submitted report does not guarantee a fix or a response time.
