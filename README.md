# WYS feedback

Report bugs and suggest improvements for **WYS: What You Said**, the native Apple Silicon app for macOS 14 and later that transcribes audio and video **on your Mac**, tells the speakers apart, records meetings and calls, and summarizes them with the model built into macOS. Maintained by **Alex / [elzuzu](https://github.com/elzuzu)**.

This public repository contains user feedback and support documentation only. Application source code and app downloads are not hosted here. The Mac App Store edition is in preparation and is not yet on sale.

- [Report a bug](https://github.com/elzuzu/wys-feedback/issues/new?template=bug-report.yml)
- [Suggest an improvement](https://github.com/elzuzu/wys-feedback/issues/new?template=feature-request.yml)
- [Search existing reports](https://github.com/elzuzu/wys-feedback/issues)
- [Support and troubleshooting](SUPPORT.md)
- [Privacy policy](PRIVACY.md) · [version française](PRIVACY.fr.md)
- [Report a security vulnerability privately](SECURITY.md)
- Other questions: **wys@elzuzu.ch.eu.org**

Please write reports **in English or French**. Include the WYS version (**WYS → About WYS**), your macOS version, your Mac model and the steps that lead to the problem.

**Issues and attachments are public.** Never attach a recording, a transcript or anything that contains other people's voices or private information: describe the problem instead, or reproduce it with a synthetic sample. Remove personal paths, names, documents, credentials and account information. The app never submits reports or logs by itself.

WYS is independent and is not affiliated with Apple. A submitted report does not guarantee a fix or a response time.
